1D Uplift & Erosion Sandbox

Relief is a reservoir: uplift fills it, erosion drains it. Erosion grows nonlinearly with relief (E = k·Rn), so relief hits a near-constant relief limit that depends only weakly on uplift rate. Drag the controls and watch relief lag the forcing while erosion chases it.

Model: dR/dt = U(t) − k·Rn, integrated with RK4. Equilibrium relief R_eq = (U/k)1/n. Pure model logic lives in model.js (no DOM), rendering in app.js — so the engine can drop into a landslidescience.org Django template later.
